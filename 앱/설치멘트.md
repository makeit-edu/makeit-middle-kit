# 메킷 키트 (코덱스 앱 판) — 수강생 흐름 · 최신판 2026-09-21

수강생 컴퓨터에 설치하는 건 없습니다. ChatGPT 앱(Plus 이상)만 있으면 됩니다.
웹 안내서(큰 글씨, 휴대폰으로 보기): https://makeit-edu.github.io/makeit-middle-kit/app.html

## 준비물

- ChatGPT 앱 (윈도우·맥) + Plus 이상 계정
- OpenAI API 키
- 워드프레스 주소 · 관리자 아이디 · 애플리케이션 비밀번호
- 수강 코드 (자료실 공지)
- 공지에서 받은 **키설정.txt** · **제목.txt**

## 처음 한 번

1. **키설정.txt** 를 메모장으로 열고 한 줄에 하나씩 순서대로 넣고 저장 (줄 사이 띄어도 됨. 수강 코드는 여기 안 넣음 — 코덱스가 채팅으로 물어봄)
   ```
   sk-여기에붙여넣기                ← OpenAI 키
   https://내사이트.com              ← 사이트 주소
   워드프레스관리자아이디             ← 관리자 아이디
   xxxx xxxx xxxx xxxx xxxx xxxx    ← 애플리케이션 비밀번호
   ```
   사이트가 여러 개면 주소 → 아이디 → 비밀번호 순서로 이어서 (최대 10개). 적은 개수만큼 등록됩니다.
2. **제목.txt** 준비 — 한 줄에 제목 하나. "주제 뽑기"로 받은 150개 파일(번호·카테고리 섞인 것)을 그대로 써도 됩니다. 프로그램이 번호 붙은 제목만 골라냅니다.
3. ChatGPT 앱 → Codex → 새 채팅 → 바탕화면에 빈 폴더 만들어 작업 폴더로 선택
4. 채팅창에 이 한 줄
   ```
   깃허브 makeit-edu/makeit-middle-kit 저장소의 README 를 읽고 거기 적힌 대로 설치해
   ```
   → "설치가 끝났어요. 먼저 수강 코드를 알려 주세요." → 수강 코드 치기 → "확인됐어요. 이제 키설정.txt 를 끌어다 놓거나 붙여넣어 주세요."
5. **키설정.txt 를 채팅창에 끌어다 놓기** (또는 내용 붙여넣기)
   → "OpenAI 키 확인 · 워드프레스 연결 확인. 키 설정이 끝났어요! 이제 제목 파일을 끌어다 놓거나 붙여넣어 주세요."
   → 틀린 줄이 있으면 어느 줄인지 알려 줌 → 그 줄만 고쳐 다시 끌어다 놓기
6. **제목.txt 를 채팅창에 끌어다 놓기**
   → "제목 150개 받았어요. (카테고리 5개) 워드프레스에 이미 있는 글 K개는 빼고, 새로 쓸 수 있는 제목이 R개예요. 임시글 몇 개 뽑아드릴까요?"
   → 사이트가 여러 개면 "먼저 1번 사이트 제목부터" 순서로 사이트마다 따로
7. 개수 답하기 — 처음엔 `1개`, 괜찮으면 `10개`
   → 글마다 게이지 줄 + 💰 줄 (이 글 토큰·돈 · 지금까지 쓴 돈)
   → 날짜는 기본으로 **하루 3개 · 최소 3시간 간격 · 시각 무작위**로 흩어집니다 (발행 누르면 그 시각에 예약 공개). "하루에 5개씩"처럼 말하면 바뀝니다
8. 끝나면 제목·발행 날짜 표 + 이번에 쓴 돈 + API 크레딧 남은 돈
   → 워드프레스 관리자 → 글 → 임시글 확인 → **발행은 직접**

## 두 번째부터

1. 코덱스 새 채팅 → 같은 폴더 → `승인글 자동화 시작해`
2. "제목이 N개 남아 있어요. 임시글 몇 개 뽑아드릴까요?" → `10개`
3. 끝나면 표 확인 → 임시글 발행

제목이 떨어지면 코덱스가 제목 파일을 다시 달라고 합니다. 키나 사이트를 바꾸려면 키설정.txt 를 고쳐 다시 끌어다 놓으면 됩니다.

## 수강생이 코덱스에게 하는 말 전부

| 말 | 언제 |
|---|---|
| 설치 문장 한 줄 | 처음 한 번 |
| 수강 코드 (채팅에 치기) | 처음 한 번, 설치 직후 |
| 키설정.txt (끌어다 놓기) | 처음 한 번 · 키/사이트 바꿀 때 (새 사이트 세 줄만 이어 적어도 됨) |
| 제목.txt (끌어다 놓기) | 키 설정 직후 · 제목이 떨어졌을 때 |
| `10개` | 만들 개수 |
| `승인글 자동화 시작해` | 두 번째부터 |
| `진단해줘` | 이상할 때 |

## 막히면

- `진단해줘` → 설정 상태 · 사이트 연결 · 만든 글 · 쓴 돈. 그 화면을 글자로 복사해 문의 (키는 가려져 나옴)
- "준비 중입니다. 10초 뒤 다시" → 앱을 막 켠 직후. 10초 뒤 같은 문장. 계속 그러면 앱 완전히 끄고 다시 켜기
- 워드프레스 연결이 계속 안 됨 → 비밀번호 연속 오류로 사이트가 잠시 잠근 것. 20~30분 뒤 다시
- ChatGPT Plus 사용량 → 코덱스 앱 계정 → 설정 → 사용량 (프로그램이 못 읽음)

## 폴더에 남는 것

- `AGENTS.md` (코덱스 대본, 자동 갱신)
- `애드센스 승인글/00_설정/` 키설정.txt · 설정.json (내 키, 남에게 보내지 말 것)
- `애드센스 승인글/01_제목넣는곳/` 제목
- `애드센스 승인글/02_생성결과_확인용/` 만든 글, 사용량 기록

프로그램 파일은 남지 않습니다. 실행할 때마다 GitHub 에서 최신판을 읽어 옵니다.
