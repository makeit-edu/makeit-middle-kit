# 메킷 키트 앱 판 — 수강생 설치 멘트 (승인글)

수강생 컴퓨터에 설치하는 건 없습니다. ChatGPT 앱(Plus 이상)만 있으면 됩니다.

## 준비 (처음 한 번)

1. ChatGPT 앱 설치 → Plus 계정 로그인 → 왼쪽 **Codex** 클릭
2. 바탕화면에 빈 폴더 하나 만들기 (이름 예: `메킷키트`)
3. 코덱스에서 **새 채팅** → 작업 폴더로 방금 만든 폴더 선택
4. 아래 한 문장을 채팅창에 치고 엔터

## 설치 — 채팅창에 이 한 문장만 (실측 2026-09-20 통과)

```
깃허브 makeit-edu/makeit-middle-kit 저장소의 README 를 읽고 거기 적힌 대로 설치해
```

코덱스가 저장소 첫 화면을 읽고 알아서 설치한 뒤, **같은 채팅에서 키 설정 파일을 채우라고 안내합니다.** 새 채팅을 열 필요 없습니다.

## 키 설정 — 공지에서 받은 txt 를 코덱스에게 주기만 하면 됩니다 (처음 한 번)

공지에 첨부된 **키설정.txt** 를 받아 메모장으로 열고 `=` 뒤에 붙여넣어 저장하세요.

```
수강코드=weolbumakeitmiddle
OpenAI키=sk-여기에붙여넣기
사이트주소=https://내사이트.com
관리자아이디=워드프레스관리자아이디
앱비밀번호=xxxx xxxx xxxx xxxx xxxx xxxx
충전한달러=10        ← 선택. 넣으면 글마다 남은 돈이 보입니다
```

설치가 끝나면 코덱스가 "키설정.txt 를 여기에 끌어다 놓거나 내용을 붙여넣어 주세요" 라고 합니다. **그 파일을 채팅창에 끌어다 놓거나, 내용을 복사해 붙여넣으세요.** 코덱스가 읽어서 수강 코드·키·워드프레스 연결을 확인하고 저장한 뒤 "키 설정이 끝났어요! 승인글 자동화를 시작할까요?" 라고 묻습니다. 틀린 줄이 있으면 어느 줄인지 알려 주니 그 줄만 고쳐 다시 붙여넣으면 됩니다.

## 그다음은 코덱스가 묻는 대로 답만 하면 됩니다

| 코덱스가 묻는 것 | 언제 | 답 |
|---|---|---|
| 키설정.txt | 처음 한 번 | 파일을 끌어다 놓거나 내용 붙여넣기 |
| 제목 | 제목이 떨어졌을 때 | 1개든 100개든 한 줄에 하나씩 |
| 몇 개 만들지 | 매번 | "1개" → 확인 후 "10개" |

글 하나가 끝날 때마다 **게이지**와 **💰 이 글에 쓴 토큰·돈 · 지금까지 · 남은 돈**이 나옵니다.
글은 워드프레스 **임시글**로만 저장됩니다. 확인한 뒤 발행 버튼은 직접 누르세요.

## 폴더에 남는 것

- `AGENTS.md` — 코덱스 대본 (건드리지 마세요)
- `애드센스 승인글/00_설정/설정.json` — 내 키·사이트 정보 (남에게 보내지 마세요)
- `애드센스 승인글/01_제목넣는곳/` — 제목 파일
- `애드센스 승인글/02_생성결과_확인용/` — 만든 글, 사용량 기록

프로그램 파일은 폴더에 남지 않습니다. 실행할 때마다 GitHub 에서 최신판을 읽어 옵니다.

## 막히면

코덱스에게 "진단해줘" 라고 하세요. 설정 상태, 사이트 연결, 지금까지 만든 글과 쓴 돈이 나옵니다. 그 화면을 글자로 복사해 문의 채널에 올리면 됩니다 (키는 가려져 나옵니다).
