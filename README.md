## 검은 창에 치는 명령

| 명령 | 하는 일 |
|---|---|
| `시작` | AI 비서(코덱스) 켜기 |
| `진단` | **뭔가 이상할 때 제일 먼저** |
| `키설정` | API 키·수강 코드 입력·변경 |
| `저장` | 작업물 보관하기 |
| `정리` | 공간이 부족할 때 |
| `업데이트` | 프로그램 최신판 받기 |

<br>

## 2주차 영상 — 한 마디면 됩니다

`영상넣는곳` 에 폴더를 만들어 영상을 올린 뒤, **`시작`** 으로 코덱스를 켜고 이렇게 말하세요.

> ### 영상 자동화 시작해

**상품 번호**와 **메킷허브 프롬프트** 두 가지만 답하면
영상 병합 → 기획안 → 이미지 → 완성 영상까지 알아서 만들어 줍니다. *(10~15분)*

<br>

단계별로 직접 하고 싶다면 아래 명령을 하나씩 써도 됩니다.

| 명령 | 하는 일 |
|---|---|
| `새상품 1` | 상품 작업 만들기 *(숫자는 폴더 번호)* |
| `이미지만들기` | 기획안 기준으로 이미지 만들기 |
| `영상만들기` | 음성 만들고 영상 렌더링 |
| `편집기` | 영상 편집기 켜기 |
| `내보내기` | 완성 영상 압축파일로 묶기 |
