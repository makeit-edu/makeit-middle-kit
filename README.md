# 월부 중급반 메킷 키트

> 이 문서는 강의 자료실의 **「메킷 키트 사용 안내서」와 같은 내용**입니다.  
> 위에서부터 번호 순서대로 따라 하면 됩니다.

---

## 내 컴퓨터에는 아무것도 설치하지 않습니다

`시작 전에`

프로그램은 인터넷 저편의 컴퓨터에서 돌아갑니다. 그래서 윈도우든 맥이든 화면도, 순서도, 결과도 똑같습니다. 크롬 브라우저만 있으면 됩니다.

**안 해도 되는 것**

- 백신 끄기
- 압축 풀기
- 프로그램 설치
- 보안 경고 씨름

**미리 챙길 것**

- 크롬이 깔린 컴퓨터
- ChatGPT Plus 계정
- OpenAI · ElevenLabs API 키
- 수강 코드 (자료실 공지)

> 🚫 **반드시 컴퓨터에서** — 태블릿·휴대폰으로는 사용할 수 없습니다. 노트북이나 데스크톱의 크롬에서 여세요.

> ⚠️ **얼마나 걸리나** — **다음 장(1~23번)만 처음 딱 한 번** 하면 됩니다. 순조로우면 20분, 천천히 해도 40분. 그 뒤로는 다시 할 일이 없습니다.

## 처음 딱 한 번만 하는 준비

`1 · 1~23번`

여기까지가 제일 낯섭니다. 한 번 끝내면 다시는 할 필요 없습니다.

### ChatGPT 스위치 하나 켜기

**1.** 크롬에서 **chatgpt.com** 에 로그인

   평소 쓰는 본인 계정이어야 합니다.

**2.** 왼쪽 아래 **내 이름** 클릭 → `설정`

**3.** `보안 및 로그인` 메뉴 클릭

**4.** 화면을 **맨 아래까지** 스크롤

**5.** **“Codex용 장치 코드 인증 활성화”** 스위치 켜기

> 🚫 **이거 안 켜면 로그인이 안 됩니다** — 여기서 로그인한 계정과 나중에 승인할 계정이 **같아야** 합니다. 가족 공용·회사 계정으로 켜지 않도록 주의하세요.

> ✅ **성공 확인** — 스위치가 초록색이면 됩니다.

### 깃허브 가입하기

**6.** **github.com/signup** 접속

**7.** 맨 위 `Continue with Google` 클릭 → 평소 쓰는 구글 계정 선택

   이메일·비밀번호를 새로 만들 필요가 없습니다. 무료이고 카드 등록도 없습니다.

**8.** **Username** 에 내가 알아볼 이름을 넣고 `Create account` 클릭

   영문·숫자·하이픈만 됩니다. 이미 쓰는 사람이 있으면 뒤에 숫자를 붙이세요. 나머지 칸은 그대로 둬도 됩니다.

> ✅ **성공 확인** — 오른쪽 위에 동그란 프로필 아이콘이 보이면 가입 완료.

### 내 작업방 만들기

**9.** 키트 링크 열기

   [github.com/makeit-edu/makeit-middle-kit](https://github.com/makeit-edu/makeit-middle-kit)

**10.** 오른쪽 위 초록색 `Use this template` 클릭

**11.** 뜨는 메뉴에서 `Create a new repository` 선택

   다음 화면 맨 위 **Start with a template** 에 `makeit-edu/makeit-middle-kit` 이 들어가 있으면 제대로 온 것입니다.

> 🚫 **바로 아래 “Open in a codespace”는 누르지 마세요** — 내 작업방 없이 임시 방이 열려서 나중에 **작업물이 통째로 사라집니다.**

**12.** **Repository name** 칸에 내가 알아볼 이름 입력

   영문·숫자·하이픈만 됩니다. 초록색 **is available** 이 뜨면 쓸 수 있는 이름입니다. **Description 칸은 비워두세요.**

**13.** 아래 **Choose visibility** 가 `Private` 인지 확인

   보통 처음부터 Private으로 되어 있습니다. 그대로 두면 됩니다.

**14.** 초록색 `Create repository` 클릭

> ✅ **성공 확인** — 주소창에 `내아이디/내가지은이름` 이 보이면 성공.

> ⚠️ **Codespaces 탭이 없고 Clone만 보인다면** — 깃허브 로그인이 안 된 상태입니다. 오른쪽 위 `Sign in` 으로 로그인한 뒤 다시 하세요. 크롬 프로필을 여러 개 쓴다면 가입했던 그 프로필인지도 확인.

### 작업방 처음 열기

**15.** 내 작업방에서 초록색 `<> Code` 버튼 클릭

**16.** `Codespaces` 탭 클릭

   Local 탭이 아닙니다.

**17.** 초록색 `Create codespace on main` 클릭

**18.** **3~10분 기다리기**

   검은 창에 영어 글자가 빠르게 흘러갑니다. **멈춘 게 아닙니다.** 이 시간에 프로그램이 알아서 다 설치됩니다. 커피 한 모금 하고 오세요.

✅ **이 화면이 나와야 끝난 것입니다** — 
 검은 창 맨 아래에 **초록색 가로줄 두 개**가 그어지고, 그 사이에 이렇게 뜹니다.
 

```
━━━━━━━━━━━━━━━━━━━━━━━━━━

 ✅ 준 비 완 료 설치가 전부 끝났습니다

 이제 이 검은 창에 아래 순서대로 입력하세요.

 1) 키설정
 2) 시작

━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**이게 보이기 전까지는 아직 설치 중**입니다. 아무것도 누르지 말고 기다리세요.

> ⚠️ **가운데 화면이 텅 비어 있어도 정상** — 안내 문서 같은 건 열리지 않습니다. **검은 창만 보이는 게 맞습니다.** 안내는 지금 보고 계신 이 안내서 하나로 충분합니다.

> 🚫 **10분이 넘어도 이 화면이 안 뜬다면** — 브라우저를 새로고침(F5) 해보세요. 그래도 안 되면 **막혔을 때** 장의 첫 번째 항목을 보세요.

### 열쇠(키) 넣기

**19.** 화면 아래 **검은 창**을 마우스로 한 번 클릭

**20.** `키설정` 치고 엔터

**21.** 물어보는 순서대로 붙여넣기

   수강 코드 → 주차 선택(엔터 = 전부) → OpenAI 키 → 워드프레스 정보 → ElevenLabs 키 순서입니다.

> ⚠️ **화면에 안 보이는 게 정상입니다** — 보안 때문입니다. 한 번만 붙여넣고 엔터. 붙여넣기는 `Ctrl`+`V` (맥 `Cmd`+`V`).

> ✅ **아직 없는 항목은 그냥 엔터** — 건너뛰어도 됩니다. 나중에 `키설정` 을 다시 실행해 그 값만 넣으면 됩니다.

### AI 비서(코덱스) 켜기

**22.** `시작` 치고 엔터

   영어 주소와 알파벳 코드가 나옵니다. 예: WNXQ-XVJIT

**23.** 코드 복사 → 주소를 `Ctrl`(맥 `Cmd`) 누른 채 클릭 → 코드 붙여넣고 승인

> 🚫 **검은 창에서는 Ctrl+C 가 복사가 아닙니다** — 마우스로 **드래그 → 우클릭 → 복사** 하세요.

> ⚠️ **영어 팝업이 뜨면 Allow(허용)** — 실수로 Block을 눌렀다면 주소창 자물쇠 → 클립보드 → 허용 → 새로고침.

> ✅ **성공 확인** — 검은 창에 코덱스 대화 화면이 뜨면 준비 완료. 이제 다시 할 일 없습니다.

## 1주차 — 애드센스 승인글

`3 · 29~36번`

뽑아둔 제목을 붙여넣고, 코덱스에게 말 한마디 걸면 끝입니다.

**29.** 왼쪽 목록에서 `01_1주차_애드센스승인` 펼치기

**30.** `01_제목넣는곳` → `사이트1_제목200개.txt` 클릭

**31.** 준비한 제목 붙여넣기

   한 줄에 제목 하나씩이 가장 좋습니다. “1. 제목” 처럼 번호가 붙어 있어도 알아서 처리됩니다.

**32.** `Ctrl`+`S` (맥 `Cmd`+`S`) 로 저장

> 🚫 **이 파일에 넣으면 안 되는 것** — 사이트 주소, 아이디, 비밀번호, API 키. **제목만** 넣으세요.

**33.** `시작` 으로 코덱스를 켜고 `애드센스 승인글 자동화 시작해줘` 입력

**34.** 몇 개 만들지 물어보면 **처음에는 반드시 1개만**

   1개 확인 → 괜찮으면 5개 → 그다음 20개씩 늘리세요.

**35.** 워드프레스 관리자에서 **임시글**과 대표이미지 확인

   승인글은 임시글로만 저장됩니다. 공개 발행되지 않습니다.

> ✅ **성공 확인** — `02_생성결과_확인용` 폴더에 오늘 날짜 파일이 생기면 완료.

**36.** 인증샷 제출 → `저장`

> 🚫 **인증샷은 결과 폴더 화면만** — 검은 창이나 키설정 화면은 절대 포함하면 안 됩니다. 키가 노출됩니다.

> ⚠️ **목표** — 사이트 1개당 임시글 **100개 이상**을 채운 뒤 애드센스를 신청하세요.

## 2주차 — 쇼핑 숏폼 영상

`4 · 37~56번`

내가 찍은 영상 → 기획안 → 이미지 → 완성 영상. 순서만 지키면 됩니다.

### ① 재료 올리기

**37.** 휴대폰 영상을 컴퓨터로 먼저 옮기기

   카톡 “나에게 보내기” → PC 카톡에서 저장이 가장 쉽습니다. 파일명은 `1.mp4, 2.mp4…` 로 바꿔두면 편합니다.

**38.** `02_2주차_쇼핑숏폼자동화` → `영상넣는곳` 우클릭 → `새 폴더`

**39.** 폴더 이름은 **번호 + 제품명**

   예: `005_에어팟맥스`

**40.** 그 폴더 안으로 영상 파일을 **마우스로 끌어다 놓기**

   여러 개를 한 번에 놓아도 됩니다. 크기에 따라 1~5분 걸리고 진행률이 표시됩니다.

> ⚠️ **업로드 중에는 탭을 닫지 마세요** — 진행률이 100%가 될 때까지 기다립니다.

**41.** 같은 폴더에 우클릭 → `새 파일` → `상품정보.txt`

**42.** 3줄 쓰고 `Ctrl`+`S` 로 저장

   1. 005번  ·  2. 에어팟맥스  ·  3. 쿠팡파트너스 링크

### ② 작업 만들기

**43.** 코덱스가 켜져 있으면 `/quit` 으로 끄기

   한글 명령은 코덱스 안이 아니라 **검은 창**에서 칩니다.

**44.** `새상품 5` 치고 엔터

   5는 내 폴더 번호(005)의 숫자입니다. 1번 상품이면 `새상품 1`.

> ✅ **성공 확인** — 올린 영상들이 하나로 합쳐지고 작업 폴더가 만들어집니다.

### ③ 기획안 만들기

**45.** 워드프레스 `메킷허브` → `프롬프트 메뉴` 에서 내 상품 프롬프트 복사

**46.** `시작` 으로 코덱스를 켜고 프롬프트 붙여넣기

**47.** 1~2분 뒤 제품 폴더에 **기획안 파일**이 생기면 성공

### ④ 이미지와 영상 만들기

## 영상 편집기로 다듬기

**57.** `편집기` 치고 엔터

**58.** 알림이 뜨면 `브라우저에서 열기` 클릭

> ⚠️ **알림을 놓쳤다면** — 화면 아래쪽 `포트 / PORTS` 탭 → 4321 줄의 지구본 아이콘을 클릭하면 열립니다.

### 고치기

**61.** **자막 고치기** — 오른쪽 `나레이션 문장` 에서 직접 고쳐 쓰기

   오타를 잡거나 문장을 더 짧게 다듬을 때.

**62.** **이미지 바꾸기** — 장면 클릭 → `내 이미지로 바꾸기` → 사진 선택

   jpg · png 만 됩니다. 사진이 너무 크면 조금 작은 걸로 다시 시도하세요.

**63.** **구간 자르기 · 삭제** — 타임라인에서 블록의 **가운데**를 클릭해 자르기

   너무 끝쪽은 잘리지 않습니다. 삭제하면 뒤 블록이 자동으로 당겨집니다.

**64.** **자막 모양 · 화면 움직임** — 오른쪽에서 글씨 크기, 자막 색, 화면 효과 고르기

   자막 색은 기본 흰색 · 노란 강조 · 검정 박스. 화면 효과는 천천히 확대 · 살짝 확대 · 움직임 없음 등.

**65.** **되돌리기** — `Ctrl`+`Z` (맥 `Cmd`+`Z`) 로 한 단계씩

   완전히 처음으로 돌리려면 `원본 복구` 버튼.

### 다시 만들기

**66.** 다 고쳤으면 `수정한 영상 다시 제작하기` 클릭

**67.** “음성도 새로 만들까요?” 라고 물으면 → **예**

> 🚫 **자막을 고쳤는데 음성을 안 만들면** — 영상 목소리는 **옛날 문장 그대로** 나옵니다. 자막을 건드렸다면 반드시 “예”.

**68.** 확인만 할 거면 `빠른 제작`, 업로드할 거면 `고화질 제작`

   빠른 제작은 화질이 조금 낮은 대신 금방 끝납니다. 여러 번 고칠 때 쓰세요.

**69.** 진행률 100% → `완성 영상 보관함` 에 새 영상이 추가됩니다

> ✅ **성공 확인** — 보관함에서 바로 재생해 확인한 뒤, 마음에 들면 다음다음 장으로.

## 더 좋게 만드는 선택 기능

`6 · 70~77번 · 선택`

**안 써도 됩니다.** 지금까지 순서만 그대로 쓰셔도 결과는 똑같이 나옵니다. “이게 좀 아쉬운데” 싶을 때만 골라 쓰세요.

**70.** `닮은이미지만들기` — 내 영상을 참고해 **내 제품과 닮은** 이미지 생성

   AI 이미지가 내 제품이랑 너무 다르게 나올 때.

**71.** `썸네일후보보기` — 내 영상에서 **선명한 장면 10장** 뽑기

   AI 썸네일보다 실제 제품 사진을 쓰고 싶을 때.

**72.** 뽑힌 후보는 `썸네일후보` 폴더에서 눈으로 고르기

**73.** `이미지바꾸기` — 장면·썸네일을 **내 사진**으로 교체

   편집기를 안 켜고도 바로 바꿀 수 있습니다.

**74.** `이미지되돌리기` — 바꾼 이미지를 원래대로

   원본은 지워지지 않고 보관됩니다.

**75.** `음성미리듣기` — 자막 고친 뒤 **음성만 먼저** 듣기

   영상은 5~10분 걸리니, 발음·억양만 먼저 확인하고 싶을 때.

**76.** 이미지를 바꿨다면 `영상만들기` 를 다시 해야 반영됩니다

**77.** 공지에 “업데이트 하세요” 가 뜨면 `업데이트`

   새 기능과 오류 수정이 자동으로 들어옵니다. 내 작업물은 그대로 남습니다.

## 막혔을 때

`참고`

대부분 여기서 풀립니다. 그래도 안 되면 `진단` 결과를 통째로 복사해 문의 채널에 올려주세요.

<details><summary><b>화면이 안 뜨고 계속 로딩만 해요</b></summary>

처음 만들 때는 **3~10분** 걸립니다. 검은 창에 영어 글자가 흘러가는 동안은 정상입니다. 초록 줄과 함께 **“✅ 준 비 완 료”** 가 뜨면 끝난 것입니다. 10분이 넘도록 안 뜨면 새로고침(F5), 그래도 안 되면 **github.com/codespaces** 에서 해당 항목 오른쪽 **…** → Delete 후 15번부터 다시 하세요.

</details>

<details><summary><b>갑자기 화면이 멈췄어요 / 꺼졌어요</b></summary>

고장이 아닙니다. 30분 동안 아무것도 안 하면 자동으로 잠듭니다. 작업방을 다시 열면 하던 작업 그대로 있습니다.

</details>

<details><summary><b>명령어를 쳤는데 “command not found” 라고 나와요</b></summary>

검은 창 위쪽의 **[+]** 버튼으로 터미널을 새로 열고 다시 해보세요. 앞뒤 공백 없이 입력했는지도 확인하세요.

</details>

<details><summary><b>로그인 코드를 승인했는데 안 돼요</b></summary>

1~5번(ChatGPT 스위치 켜기)을 다시 확인하세요. 그리고 **로그인한 ChatGPT 계정과 스위치를 켠 계정이 같은지** 보세요.

</details>

<details><summary><b>키를 붙여넣었는데 화면에 아무것도 안 보여요</b></summary>

원래 안 보입니다(보안). 한 번만 붙여넣고 엔터를 누르세요.

</details>

<details><summary><b>붙여넣기 자체가 안 돼요</b></summary>

처음 뜬 영어 팝업에서 Block을 누른 것입니다. 주소창 자물쇠 아이콘 → 클립보드 → 허용 → 새로고침.

</details>

<details><summary><b>편집기가 안 열려요</b></summary>

화면 아래 **포트 / PORTS** 탭에서 4321 줄의 지구본 아이콘을 클릭하세요. 그래도 없으면 검은 창에서 `Ctrl`+`C` 로 끄고 **편집기** 를 다시 실행하세요.

</details>

<details><summary><b>영상 자막이 네모(□)로 나와요</b></summary>

옛날 버전입니다. 검은 창에 **업데이트** 를 치고 엔터 → 끝나면 **영상만들기** 를 다시 하세요.

</details>

<details><summary><b>돈이 나가나요?</b></summary>

작업방(깃허브)은 **무료**입니다. 카드를 등록하지 않으면 요금이 청구되는 일 자체가 없습니다. 무료 사용 시간은 월 약 60시간이며 주 5시간 실습 기준으로 넉넉합니다. ChatGPT Plus와 API 키 비용만 기존과 똑같이 나갑니다.

</details>

<details><summary><b>작업물이 사라질까 봐 걱정돼요</b></summary>

작업이 끝날 때마다 **저장** 만 눌러두면 됩니다. 30일 넘게 접속하지 않아 작업방이 삭제돼도, 저장한 내용은 새 작업방을 만들면 그대로 되살아납니다.

</details>

<details><summary><b>진행률 체크는 어디에 저장되나요?</b></summary>

이 안내서를 연 **내 브라우저에만** 저장됩니다. 어디로도 전송되지 않습니다. 다른 컴퓨터에서 열면 처음부터 시작합니다.

</details>
