코덱스에 말하면 내 깃허브에 비공개 키트가 생기고, 바꾸고 싶은 걸 말하면 코덱스가 고쳐 줘요.
원래 키트는 그대로라 언제든 돌아갈 수 있어요.

먼저 챙길 것

  • 1·2주차에 쓰던 작업 폴더 — 원본 키트 설치·키 설정이 끝난 그 폴더 그대로
  • 깃허브 계정 — 없으면 github.com 에서 무료로 직접 가입 (코덱스가 대신 가입하지 않아요)
  • 크롬 — 깃허브 화면에서 코드 한 번 넣는 데만 씁니다
내 컴퓨터에는 아무것도 내려받지 않아요키트 코드는 내 깃허브(비공개)에만 있고, 고치는 것도 코덱스가 깃허브에 바로 해요. 토큰 복사, 저장소 만들기, 코드 편집기 같은 건 하나도 없습니다.

막혔을 때

“아직 승인이 안 됐어요”깃허브 화면에서 코드를 넣고 초록 Authorize 까지 눌렀는지 확인하고 다시 “했어요”.
승인 화면이 ‘Page not found’ 예요새로고침하면 그래요. 코덱스에 “다시 해줘” 라고 하면 새 코드를 줘요.
“코드 시간이 지났어요”코덱스가 새 코드를 줘요. 15분 안에 넣으면 됩니다.
“깃허브 연결이 끊겼어요”내 커스텀 키트 만들어줘 라고 하면 다시 연결돼요. 내 키트는 깃허브에 그대로 있어요. 급하면 원본 키트로 써줘.
바꾼 뒤 이상해요방금 바꾼 거 되돌려줘. 원본 키트로 같은 일이 잘 되면 내가 바꾼 부분 때문이에요.
내 키트를 깃허브에서 보고 싶어요github.com/내아이디/my-makeit-kit (나만 볼 수 있어요)
연결을 끊고 싶어요깃허브 → Settings → Applications → Authorized OAuth Apps → 메킷 키트 → Revoke. 그 뒤엔 원본 키트로 쓰면 돼요.
촬영할 때이 방식은 토큰 같은 비밀값이 화면에 나오지 않아요. 8자리 코드는 15분짜리 한 번용이라 찍혀도 괜찮습니다. 다만 깃허브 아이디·저장소 이름이 보이니 촬영용 깃허브 계정을 쓰면 좋아요.
강사용 — 어떻게 도는지 · 주의할 점 · 검증 범위

어떻게 도는지. ‘내 커스텀 키트 만들어줘’ → makeit-edu 의 깃허브 OAuth 앱 ‘메킷 키트’ 로 디바이스 로그인(권한 repo) → 키트가 원본 템플릿에서 수강생 계정에 비공개 저장소 my-makeit-kit 를 만들고(POST …/generate), 같은 작업 폴더의 애드센스 승인글/00_설정 에 표시(키트저장소.txt)·연결 정보(내키트.json)·연결 토큰(깃허브토큰.txt, 권한 600)을 둡니다. 그 폴더는 실행할 때마다 내 키트 main 의 최신 커밋을 받아 씁니다. ‘내 키트에서 ○○ 바꿔줘’ → 코덱스가 파일을 읽고 바꿀 곳을 주면 키트가 검사(JSON·불러오기·비밀값·대본 필수 줄)한 뒤 깃허브에 한 커밋으로 올립니다. 되돌리기는 직전 커밋 이전 상태로 새 커밋. 내 키트로 돌 때도 만들기·고치기·설치 부품은 늘 원본 것이 돌고, 원본 키트 요청에는 토큰을 붙이지 않습니다. 전역 ~/.codex/AGENTS.md 는 원본 그대로.

주의. ① 원본 목록.json 의 정지 스위치로 수강생 키트는 멈출 수 없습니다 — 각자 사본입니다. ② 원본이 좋아져도 내 키트에는 자동으로 안 들어갑니다(원본 키트로 써줘, 또는 ‘원본에 새로 나온 ○○ 내 키트에도 넣어줘’). ③ 깃허브 OAuth 의 비공개 저장소 권한은 ‘repo’(그 계정의 모든 저장소) 하나뿐입니다. 키트 코드는 시킨 일만 하고, 수강생은 언제든 Revoke 할 수 있습니다. ④ 수강생 PC 에 코드를 내려받지 않습니다(검사용 임시 폴더는 바로 지움).
