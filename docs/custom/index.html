순서로 바로가기

월부월백 중급반 · 내 커스텀 키트

키트를 내 깃허브로 가져가
내 마음대로 고쳐 쓰기

1·2주차 키트를 내 깃허브의 비공개 저장소로 복사해서, 나만의 키트로 고쳐 씁니다.
원래 키트는 그대로 두고 둘 다 계속 쓸 수 있어요.

내 컴퓨터로 내려받지 않습니다키트 코드는 내 깃허브(비공개)에만 있고, 고치는 것도 코덱스 웹(chatgpt.com/codex)에서만 합니다. 내 컴퓨터의 코덱스 앱은 지금처럼 쓰기만 해요. 저장소를 내려받거나(다운로드·git clone) 내 컴퓨터에서 파일을 고치지 않습니다.

먼저 챙길 것

  • 1·2주차에 쓰던 작업 폴더 — 원본 키트 설치·키 설정이 끝난 폴더
  • 크롬 — 깃허브 화면은 크롬에서 직접 누릅니다
  • 깃허브 계정 — 없으면 github.com 에서 무료로 직접 가입 (코덱스가 대신 가입하지 않아요)
  • ChatGPT Plus 이상 — 키트를 고칠 때 쓰는 코덱스 웹(chatgpt.com/codex)

전체 순서: ① 깃허브에 비공개 복사본 → ② 읽기 전용 토큰 → ③ 코덱스에 연결 → ④ 새 폴더로 쓰기 → ⑤ 코덱스 웹에서 고치기 → ⑥ Merge 하면 바로 반영

1

깃허브에 비공개 복사본 만들기

크롬에서 깃허브에 로그인한 뒤 아래 주소를 엽니다.

Repository name 에 내 저장소 이름(예: my-makeit-kit)을 넣고, Private 을 고른 뒤 맨 아래 초록 버튼 Create repository 를 누릅니다.

주소 대신 버튼으로 가도 됩니다원본 저장소 화면(github.com/makeit-edu/makeit-middle-kit) 오른쪽 위 초록 Use this template → Create a new repository 를 누르면 같은 화면이 나와요.

2

읽기 전용 토큰 만들기

비공개 저장소라 내 컴퓨터의 코덱스가 읽으려면 열쇠(토큰)가 하나 필요해요. 아래 주소를 열면 이름·권한·기간이 미리 채워져 있습니다.

토큰 만들기 화면 열기 (미리 채워진 주소) ↗

내가 할 것은 둘뿐입니다: Repository access 에서 Only select repositories → 방금 만든 저장소 고르기, 그리고 맨 아래 Generate token.

토큰은 비밀번호처럼화면을 닫으면 다시 볼 수 없어요. 남에게 보내거나 카톡·카페에 올리지 마세요. 잃어버리면 같은 주소로 새로 만들면 됩니다.
3

코덱스에 연결 — 원래 폴더에서

ChatGPT 앱 → Codex → 새 채팅 → 작업 폴더로 1·2주차에 쓰던 폴더를 고르고 이렇게 말합니다.

내 커스텀 키트 만들어줘

코덱스가 1·2번(복사본·토큰)을 안내하고 기다립니다. 이미 했으면 내 저장소 주소와 토큰을 붙여넣으세요.

코덱스 채팅 · 설명용 그림

내 커스텀 키트 만들어줘

https://github.com/내아이디/my-makeit-kit

내 커스텀 키트를 연결했어요 (비공개). 이 컴퓨터에는 ‘메킷 커스텀 키트’ 폴더를 만들었어요. (키 설정은 그대로 옮겨 놨어요)

코덱스가 하는 일저장소와 토큰이 맞는지 확인하고, 원래 폴더 옆에 메킷 커스텀 키트 폴더를 만들어 내 저장소로 돌게 설정해요. 토큰은 그 폴더 설정에만 저장되고, 원래 폴더는 그대로입니다.
4

내 커스텀 키트로 쓰기

원본원래 작업 폴더지금까지처럼 원본 키트
·
내 것메킷 커스텀 키트내 비공개 저장소로 도는 키트

코덱스에서 새 채팅 → 작업 폴더로 메킷 커스텀 키트 를 고르고 평소처럼 말하면 됩니다 (승인글 자동화 시작해, 네이버 글 써줘, 메킷애센 고쳐줘).

아직 아무것도 안 고쳤다면내 커스텀 키트도 처음에는 원본과 똑같이 돌아요. 5번에서 고치면 그때부터 달라집니다.
5

고치기 — 코덱스 웹에서

컴퓨터 브라우저로 chatgpt.com/codex 에 들어갑니다.

  1. 처음 한 번: 깃허브 연결(Connect GitHub) → 내 깃허브 계정에서 접근 허용 — 이때 내 비공개 저장소(my-makeit-kit)도 허용해야 목록에 보여요.
  2. 저장소 목록에서 내아이디/my-makeit-kit 를 고릅니다.
  3. 바꾸고 싶은 것 한 가지를 적고 보냅니다.
  4. 코덱스가 고친 내용을 보여 주면 Create PR(PR 만들기)을 누릅니다.

네이버 글 마무리 문단 끝에 "이웃 추가하시면 새 글을 바로 받아 보실 수 있어요" 한 문장을 늘 넣어줘. 다른 건 바꾸지 마.

무엇을 바꿀지 모르겠다면이 키트에서 내가 바꿀 만한 것 세 가지를 쉽게 제안해줘. 아직 고치지 마. 라고 먼저 물어보세요.
내 컴퓨터 코덱스에게 고쳐 달라고 하면“키트 고치기는 온라인에서 해요” 라고 안내만 합니다. 고치기는 꼭 코덱스 웹에서 하세요.
키·비밀번호·토큰은 절대 적지 마세요코덱스 웹에서 고칠 때도 OpenAI 키·워드프레스 비밀번호·토큰은 적지 않습니다. 키는 지금처럼 내 컴퓨터의 키설정으로만 넣어요.
6

깃허브에서 Merge — 다음 실행부터 바로 반영

PR 화면(깃허브)에서 Merge pull request → Confirm merge 를 누르면 끝입니다. 메킷 커스텀 키트 폴더에서 다음 실행부터 바로 바뀐 대로 돕니다 (켜 둔 채팅도 2분 안에 바뀝니다).

마음에 안 들면 되돌리기깃허브의 그 PR 화면에서 Revert → 새로 생긴 PR 을 Merge 하면 원래대로 돌아가요. 코덱스 웹에 방금 바꾼 걸 되돌려줘 라고 해도 됩니다.

막혔을 때

“토큰이 있어야 해요”2번대로 토큰을 만들어 붙여넣으세요.
“저장소를 찾지 못했어요”주소가 맞는지, 토큰 만들 때 Only select repositories 에서 내 저장소를 골랐는지 확인하세요. 안 골랐으면 토큰을 새로 만듭니다.
“토큰이 틀렸거나 만료·삭제됐어요”새 토큰을 만들고 깃허브 토큰 바꿔줘 라고 한 뒤 붙여넣으세요.
“원본 키트 주소예요”원본(makeit-edu/makeit-middle-kit)이 아니라 1번에서 만든 내 저장소 화면의 주소를 주세요.
코덱스 웹에 내 저장소가 안 보여요깃허브 연결 설정에서 내 비공개 저장소 접근을 허용했는지 확인하세요.
고친 뒤 오류가 나요원래 폴더에서 같은 일이 되면 내가 고친 부분 때문입니다. 6번의 Revert 로 되돌리세요.
원본 키트가 좋아졌대요원래 폴더에는 저절로 들어와요. 내 커스텀 키트에는 저절로 안 들어오니, 새 기능은 원래 폴더에서 쓰거나 코덱스 웹에 “원본 makeit-edu/makeit-middle-kit 의 새 내용을 합쳐줘” 라고 하세요.
촬영할 때 — 토큰이 화면에 나오지 않게2번의 Generate token 직후 화면과, 3번에서 토큰을 붙여넣는 장면에 토큰 값이 그대로 보입니다. 녹화본에서 그 부분을 가리거나 흐리게 하고, 촬영이 끝나면 그 토큰을 지우세요 (깃허브 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 그 토큰 Delete). 실제 수강생 계정 대신 촬영용 깃허브 계정을 쓰면 더 안전합니다.
강사용 — 어떻게 도는지 · 주의할 점 · 검증 범위

어떻게 도는지. 원본 저장소 makeit-edu/makeit-middle-kit 는 템플릿으로 켜 둠(2026-10-19). 수강생이 ‘Use this template’ → Private 로 복사하면 원본과 이력이 이어지지 않은 독립 저장소(커밋 1개)가 됩니다. ‘내 커스텀 키트 만들어줘’ → 코덱스가 저장소·토큰을 확인하고 원래 폴더 옆 ‘메킷 커스텀 키트’ 폴더에 대본(AGENTS.md)을 깔며, 준비 코드의 저장소 줄을 수강생 저장소로 바꾸고 애드센스 승인글/00_설정/키트저장소.txt 표시와 깃허브토큰.txt(읽기 전용 토큰, 파일 권한 600)를 둡니다. 그 폴더는 실행할 때마다 수강생 저장소 main 의 최신 커밋을 토큰으로 받아 씁니다. 원본 폴더·전역 ~/.codex/AGENTS.md 는 그대로이고, 원본 저장소로 가는 요청에는 토큰을 붙이지 않습니다.

주의. ① 원본 목록.json 의 정지 스위치로 수강생 복사본은 멈출 수 없습니다 — 각자 사본입니다. ② 원본이 바뀌어도 복사본에는 자동으로 안 들어갑니다(템플릿이라 Sync fork 없음). ③ 토큰은 무기한·읽기 전용·그 저장소 하나만으로 만들게 안내합니다. 1년 넘게 안 쓰면 깃허브가 지울 수 있어요. ④ 코덱스 웹이 저장소를 고칠 때 지키는 규칙은 저장소 맨 위 AGENTS.md ‘이 저장소를 고칠 때’ 에 있습니다(로더·설치·커스텀 파일은 고치지 않음, 새 파일은 목록.json 에 등록, 키·토큰 금지).

검증 범위 (2026-10-19). 원본을 실제 템플릿으로 복사한 비공개 저장소(makeit-edu/kit-template-test, 비공개)와 토큰으로 34개 항목 통과: 연결(주소 없음·원본 주소·토큰 없음·틀린 토큰·없는 저장소·옛 판·토큰 꼴), 새 폴더(토큰 파일 권한 600·표시·대본 저장소 줄·전역 대본 그대로), 비공개 저장소 최신 커밋으로 실행, 토큰 틀림·없음 안내와 ‘깃허브 토큰 바꿔줘’ 복구, 원본 요청에 토큰 안 붙음. 아직 확인 전: 수강생이 웹에서 만드는 fine-grained 토큰(github_pat_)으로의 실측(시험은 같은 방식으로 붙는 다른 깃허브 토큰), 코덱스 웹 화면 이름, Windows.
