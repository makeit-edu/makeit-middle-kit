월부월백 중급반

메킷 키트
시작하기

컴퓨터에 아무것도 설치하지 않습니다.
크롬만 있으면 됩니다. 10단계면 끝나요.

먼저 챙길 것

  • 크롬이 깔린 컴퓨터 (노트북·데스크톱)
  • ChatGPT Plus 계정
  • OpenAI · ElevenLabs API 키 — 자료실 「키 발급 가이드」
  • 수강 코드 — 자료실 공지

휴대폰·태블릿으로는 작업할 수 없습니다. 이 안내서는 휴대폰으로 봐도 됩니다.

1

ChatGPT에서 스위치 하나 켜기

chatgpt.com 로그인 → 왼쪽 아래 내 이름 → 설정
→ 보안 및 로그인 → 맨 아래까지 스크롤
→ “Codex용 장치 코드 인증 활성화” 켜기

이거 안 켜면 7번에서 막힙니다 여기서 로그인한 계정과 나중에 승인할 계정이 같아야 합니다.
2

깃허브 가입하기

github.com/signup 접속 → 맨 위 Continue with Google 클릭

평소 쓰는 구글 계정을 고르고, Username 에 내가 알아볼 이름을 넣은 뒤 Create account.

무료입니다카드 등록 없습니다.
3

내 작업방 만들기

아래 주소를 누르면 만들기 화면이 바로 열립니다.

github.com/new?template_name=makeit-middle-kit&template_owner=makeit-edu

Repository name 에 내가 알아볼 이름 입력
→ Description 은 비워두기
→ Private 인지 확인 → Create repository

꼭 이 주소로 만드세요 원본 키트에서 바로 작업하면 저장이 안 되고 나중에 전부 사라집니다.
4

작업방 열기

방금 만들어진 내 저장소 화면에서
초록색 <> Code → Codespaces 탭 → Create codespace on main

Local 탭이 아닙니다 반드시 Codespaces 탭에서 누르세요.
5

3~10분 기다리기

검은 창에 영어 글자가 빠르게 흘러갑니다. 멈춘 게 아닙니다. 커피 한 모금 하고 오세요.

아래 화면이 나오면 끝난 것입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━ ✅ 준 비 완 료 설치가 전부 끝났습니다 이제 이 검은 창에 아래 순서대로 입력하세요. 1) 키설정 2) 시작 ━━━━━━━━━━━━━━━━━━━━━━━━━
6

열쇠(키) 넣기

검은 창을 한 번 클릭하고 키설정 치고 엔터.

수강 코드 → 주차 선택 → API 키 2개 → 워드프레스 정보 순서로 물어봅니다. 아직 없는 건 엔터로 건너뛰면 됩니다.

화면에 점(••••)만 보이는 게 정상 키는 비밀번호라 가려집니다. 한 번만 붙여넣고 엔터.
7

AI 비서 켜기

검은 창에 시작 치고 엔터.

알파벳 코드와 주소가 나옵니다. 코드를 드래그 → 우클릭 → 복사 한 뒤, 주소를 Ctrl(맥 Cmd) 누른 채 클릭해 새 탭에서 열고 붙여넣어 승인하세요.

검은 창에서는 Ctrl+C 가 복사가 아닙니다 꼭 마우스로 드래그한 뒤 우클릭 → 복사.
8

작업 시작하기

1주차 — 애드센스 승인글
제목 파일에 제목을 붙여넣고, 코덱스에 애드센스 승인글 자동화 시작해줘 라고 입력.

2주차 — 쇼핑 숏폼 영상
왼쪽 영상넣는곳 에 폴더를 만들어(예: 005_에어팟맥스) 영상을 끌어다 놓고, 코덱스에 이렇게 입력하세요.

영상 자동화 시작해

물어보는 건 두 가지뿐 ① 상품 번호  ② 메킷허브 프롬프트
답하면 영상 병합 → 기획안 → 이미지 → 완성 영상까지 알아서 만들어 줍니다. (10~15분)
9

끝나면 저장하기

검은 창에 저장 치고 엔터. 그다음 탭을 그냥 닫으면 됩니다.

저장은 습관으로 30일 동안 한 번도 안 들어오면 작업방이 삭제됩니다. 저장해 둔 것은 되살릴 수 있습니다.
10

다음부터는 여기로

github.com/codespaces

만들어둔 작업방을 클릭하면 1분 만에 하던 그대로 열립니다. 1~7번은 다시 하지 않습니다.
