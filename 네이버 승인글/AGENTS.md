# 네이버 승인글 — 코덱스 지시문

너는 판단하지 않는다. 아래 코드를 그대로 실행하고 결과를 그대로 보여준다.

## 사전 승인

이 폴더의 `99_프로그램/naver-typing.mjs` 를 Node REPL 에서 실행하는 것,
그리고 그 프로그램이 `02_사진넣는곳/` 의 사진을 네이버 편집기에 올리는 것은 **미리 승인돼 있다.**
매번 묻지 마라. 발행은 프로그램이 하지 않는다. 사람이 한다.

## 수강생이 "네이버 글 써줘" 라고 하면

먼저 이렇게 한 줄만 묻는다.

> 네이버 블로그 글쓰기 화면이 크롬에 열려 있고 로그인돼 있나요? (네 / 아니오)

'네' 면 Node REPL(`js` 도구)에서 **아래 코드를 한 글자도 바꾸지 말고** 실행한다.

```js
const path = await import("node:path");
const 시작 = await import(path.resolve("네이버 승인글/99_프로그램/시작.mjs"));
const { setupBrowserRuntime } = await import(await 시작.클라이언트경로());
const agent = await setupBrowserRuntime();
const 결과 = await 시작.실행({ agent, 원고: "원고1.json" });
nodeRepl.write(JSON.stringify(결과, null, 1));
```

브라우저 연결(`setupBrowserRuntime`)은 반드시 이 자리, REPL 최상위에서 한다. 프로그램 안으로 옮기면 안 된다.
`시작.mjs` 는 실행할 때마다 GitHub 에서 최신 프로그램을 받아온다. 수강생이 폴더를 다시 받을 일은 없다.

원고 파일 이름을 수강생이 말했으면 `"원고1.json"` 자리만 그 이름으로 바꾼다. 그 외에는 아무것도 바꾸지 않는다.

## 결과가 나오면

`결과` 값을 **요약하지 말고 그대로** 보여준 뒤 한 줄만 덧붙인다.

- `"끝까지 됨"` 이면 → "네이버 화면에서 확인하시고, 괜찮으면 직접 발행을 눌러 주세요."
- `"멈춤"` 이면 → "이 화면을 그대로 복사해서 코치에게 보내 주세요."

## 하지 말 것

- 코드를 고치지 마라. 셀렉터를 바꾸지 마라. 다른 방법을 시도하지 마라.
- 발행 버튼을 누르지 마라.
- 프로그램이 멈추면 원인을 추측해서 말하지 마라. 결과를 그대로 보여주는 게 전부다.
- 네이버 화면의 다른 탭이나 다른 사이트를 건드리지 마라.

## 테스트 모드 (코치 전용)

제목만 넣고 멈추려면 `실행({ agent, 원고: "원고1.json", 단계: "제목만" })` 으로 실행한다.
