# 네이버 글 자동 타이핑 — 수강생이 붙여넣는 멘트 2개

수강생은 파일을 받지 않습니다. 코덱스 앱에서 **새 채팅**을 열고 아래 멘트를 순서대로 붙여넣기만 합니다.

## 준비 (한 번만)

1. ChatGPT(코덱스) 앱 설치 → 로그인
2. 코덱스 앱 설정 → 컴퓨터 사용 → **Chrome 확장 설치**
3. 크롬 주소창에 `chrome://extensions` → ChatGPT 확장 **세부정보** → **파일 URL에 대한 액세스 허용** 켜기 (사진 업로드용)
4. 크롬에서 네이버 로그인
5. 코덱스 앱에서 **새 채팅** 열기

## 멘트 1 — 설치 (한 번만)

```
MCP 서버 node_repl 의 js 도구에서 아래 코드를 한 글자도 바꾸지 말고 실행하고, 출력을 그대로 보여줘라. 터미널 명령은 쓰지 마라. 경로도 바꾸지 마라.

const fs = await import("node:fs/promises");
const path = await import("node:path");
const 뿌리 = path.resolve("네이버 승인글");
const 원격 = "https://raw.githubusercontent.com/makeit-edu/makeit-middle-kit/main/" + encodeURIComponent("네이버 승인글") + "/";
const 파일들 = ["AGENTS.md", "99_프로그램/시작.mjs", "99_프로그램/naver-typing.mjs", "99_프로그램/recipe.json", "99_프로그램/글만들기.mjs", "01_원고넣는곳/원고1.json", "02_사진넣는곳/예시.png"];
const 기록 = {};
for (const f of 파일들) {
  const 주소 = 원격 + f.split("/").map(encodeURIComponent).join("/") + "?t=" + Date.now();
  const r = await fetch(주소, { cache: "no-store" });
  if (!r.ok) { 기록[f] = "실패 HTTP " + r.status; continue; }
  const 목적지 = path.join(뿌리, f);
  await fs.mkdir(path.dirname(목적지), { recursive: true });
  await fs.writeFile(목적지, Buffer.from(await r.arrayBuffer()));
  기록[f] = "받음";
}
nodeRepl.write(JSON.stringify({ 폴더: 뿌리, 기록 }, null, 1));
```

전부 "받음" 이면 끝. 이후 프로그램 업데이트는 자동입니다(실행할 때마다 GitHub 최신판을 받습니다).

## 멘트 2 — 글 쓰기 (매번)

크롬에 네이버 로그인이 돼 있어야 합니다. 글쓰기 탭은 안 열어도 됩니다(프로그램이 엽니다).

```
네이버 승인글/AGENTS.md 를 읽어라. 거기 적힌 대로만 한다.
네이버 블로그 글쓰기 화면은 크롬에 로그인된 채 열려 있다 (질문하지 말고 진행).

MCP 서버 node_repl 의 js 도구에서 아래 코드를 한 글자도 바꾸지 말고 실행하고,
결과를 요약하지 말고 그대로 보여줘라. 터미널 node 는 절대 쓰지 마라.

const path = await import("node:path");
const 시작 = await import(path.resolve("네이버 승인글/99_프로그램/시작.mjs"));
const { setupBrowserRuntime } = await import(await 시작.클라이언트경로());
const agent = await setupBrowserRuntime();
const 결과 = await 시작.실행({ agent, 원고: "원고1.json" });
nodeRepl.write(JSON.stringify(결과, null, 1));

이 폴더 스크립트 실행과 02_사진넣는곳의 사진 업로드는 사전 승인돼 있다. 발행은 하지 않는다.
```

결과에 `"결과": "끝까지 됨"` 이면 네이버 화면에서 확인하고 직접 발행. `멈춤` 이면 그 화면을 코치에게.
