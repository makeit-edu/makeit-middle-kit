# 네이버 글 자동 타이핑 — 수강생 안내

수강생이 붙여넣는 코드는 **설치 멘트 하나**뿐입니다. 그 뒤로는 코덱스가 묻고 수강생은 답만 합니다.

## 준비 (한 번만)

1. ChatGPT(코덱스) 앱 설치 → 로그인
2. 코덱스 설정 → 컴퓨터 사용 → **Chrome 확장 설치**
3. 크롬 주소창 `chrome://extensions` → ChatGPT 확장 **세부정보** → **파일 URL에 대한 액세스 허용** 켜기 (사진 업로드용)
4. 바탕화면에 빈 폴더 `네이버글` 만들기
5. 코덱스 앱에서 **새 채팅** → 작업 폴더로 `네이버글` 선택

## 그 다음은 대화입니다

설치 뒤 **채팅을 한 번 닫았다가 새 채팅**을 같은 폴더로 엽니다(코덱스가 대본 파일을 새로 읽게). 그리고 이렇게만 칩니다.

> 네이버 글 쓰고 싶어요

코덱스가 순서대로 묻습니다. 수강생은 답만 합니다.

| 코덱스가 묻는 것 | 수강생이 하는 것 |
|---|---|
| OpenAI API 키를 붙여넣어 주세요 (처음 한 번) | 키 붙여넣기 |
| 크롬에서 네이버에 로그인해 주세요. 되면 "됐어요" | 크롬에서 로그인 → "됐어요" |
| 어떤 주제(키워드)로 글을 쓸까요? | 키워드 또는 따라 쓸 네이버 글 주소 |
| (2~3분) 글과 사진을 만드는 중 | 기다림 |
| (3~4분) 네이버에 글을 씁니다. 크롬 창을 건드리지 마세요 | 지켜봄 |
| 다 썼습니다. 네이버에서 읽어 보고 '발행'을 직접 눌러 주세요 | 읽고 발행 |

다음 글은 "또 쓰자" 하면 키워드부터 다시 묻습니다. 키와 로그인은 다시 안 묻습니다.
